Vice Coast — Cover Studio turns a person's photo and a caption into cover art in the style of GTA 6's posters — the multi-panel cover look with bold lettering and a Vice City sunset or neon colour grade — and exports it as a PNG to share. Four layouts, five colour grades, up to six photos with per-panel crop, zoom and pan, and export in the common post sizes. It runs offline in a desktop browser from its own static files: the photos never leave the machine. All artwork, lettering and fonts are original — no Rockstar Games logo, official artwork or fonts.

## Run it

```sh
node serve.ts --port 8080
```

Opens the editor at http://localhost:8080. Static files only, no build step, no network.
